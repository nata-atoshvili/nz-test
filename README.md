# LOM AI

Учебный чат с mock-агентом: несколько диалогов, streaming, калькулятор, остановка и повтор после ошибки.
Без backend и внешних AI API. [Демонстрация](docs/demo.webm).

## Запуск

Node.js 22.12+ в ветке 22 или 24+.

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173.

## Технологии и архитектура

React и TypeScript используются для компонентов и строгой типизации, Vite для сборки приложения.
Zustand хранит состояние диалогов, Ant Design предоставляет готовые UI-компоненты.
SCSS Modules позволяют изолировать стили с БЭМ, Vitest проверяет логику.

`agent` с искусственными задержками выдаёт статусы, события калькулятора и фрагменты текста.
`store` обрабатывает события, `components` постепенно дополняют ответ.
Запросы привязаны к своим чатам, отменяются через AbortController. История сохраняется в localStorage.
Для одного экрана выбрана простая структура без дополнительных слоёв FSD.

Проверки: `npm test`, `npm run lint`, `npm run format:check`, `npm run build`.

## Ограничения

Агент работает по нескольким сценариям. История доступна только в текущем браузере.
Если бы продолжала разработку, подключила бы реальный API агента и добавила отображение Markdown и формул.

Если бы приложение расширилось за счёт курсов, заданий и личного кабинета, рассмотрела бы переход на FSD для разделения функциональных областей. Для текущего объёма выбрала простую структуру без дополнительных слоёв.

## Использование ИИ

Один из примеров: переработала предложенную структуру приложения. Отделила логику mock-агента от компонентов, а сохранение истории вынесла из хранилища в отдельный модуль. Благодаря этому интерфейс, обработка запросов и работа с localStorage решают отдельные задачи, и их проще изменять независимо друг от друга.
